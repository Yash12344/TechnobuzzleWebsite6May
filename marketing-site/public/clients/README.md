# Client logos — drop them here

Save each client logo here as a transparent PNG (or SVG) using **exactly**
the filename below, then edit `components/ClientsSection.tsx` and change
that client's `logo: null` to `logo: "/clients/<filename>"`.

Recommended: ~512×512 PNG with transparent background, or any SVG.

| `blessed-ayurveda.png`         | Blessed Ayurveda Hospital    |
| `gict.png`                     | GICT Dehradun                |
| `doon-defence-school.png`      | Doon Defence School          |
| `ddcp.png`                     | Doon Defence Career Point    |
| `eta-education.png`            | ETA Education                |
| `vaidyakulam.png`              | Vaidyakulam Ayurveda         |
| `charmwood.png`                | Charmwood International      |
| `mussoorie-mist.png`           | Mussoorie Mist Villa         |
| `sabhyan.png`                  | Sabhyan Real Estate          |
| `tdg-hotels.png`               | TDG Hotels                   |
| `sunshine-sprouts.png`         | Sunshine Sprouts             |

Until a logo file is added + the `logo` field is updated, each card
shows a clean wordmark of the client's name — so the section never
looks broken while you're collecting logos.
