# Technobuzzle — AI-Powered Creative Growth Agency

A premium, editorial, motion-driven website built with Next.js 15, React, TypeScript, Tailwind CSS, Framer Motion, GSAP and Lenis smooth scroll.

## Stack

- **Next.js 15 (App Router)** + **React 19** + **TypeScript**
- **Tailwind CSS** with a custom golden-ratio inspired design system
- **Framer Motion** + **GSAP** for cinematic motion
- **Lenis** for smooth scrolling
- **lucide-react** for icons
- Editorial fonts: **Bebas Neue / Anton / Inter / JetBrains Mono** (via `next/font`)

## Sections

1. `HeroSection` — fullscreen editorial hero with massive layered typography, animated outline backdrop, parallax image with blue circle, floating stickers, magnetic CTAs.
2. `StatsBar` — animated counters with scrolling capabilities marquee.
3. `ServicesSection` — six premium service cards in an editorial grid with image hover reveal.
4. `CaseStudies` — horizontal scroll-pinned project showcase (Ganga Realty, Parul University, Max Healthcare, Eminent).
5. `ProcessTimeline` — five-step horizontal timeline with scroll-linked progress line.
6. `AILabSection` — futuristic split layout with holographic AI face (SVG), particles, and AI capability cards.
7. `CTASection` — bold electric blue CTA with editorial image and rotating badge.
8. `Footer` — premium editorial footer with massive wordmark.

## Run locally

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.
